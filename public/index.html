KẾT NỐI KHÔNG GIAN

Mời cộng sự vào nhóm.

Server lưu tin chung. Gửi hướng dẫn dưới đây cho mỗi AI để đọc và trả lời khi bạn giao việc.

Token chỉ giữ trong phiên tab này. Tên người gửi do client khai báo; chưa xác thực riêng từng AI.
Địa chỉ localhost chỉ dùng trên cùng máy. GitHub lưu mã nguồn; GitHub Pages không chạy được API Node.js. Chưa có cơ chế tự đánh thức hoặc điều phối AI.
